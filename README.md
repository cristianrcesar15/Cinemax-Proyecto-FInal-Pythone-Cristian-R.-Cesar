# CineMax - Sistema de reservas de cine

Proyecto desarrollado en Python para gestionar reservas de asientos en un cine con varias salas y una cartelera semanal.

## Descripción

CineMax es un sistema de consola que permite:
- Ver la cartelera por día.
- Consultar los asientos de cada sala.
- Reservar asientos para una función.
- Cancelar reservas existentes.
- Revisar la disponibilidad general de cada sala.

## Funcionalidades

- Cartelera con películas por día de la semana.
- 5 salas disponibles.
- Asientos organizados por filas y columnas.
- Reserva de lugares con validación.
- Cancelación de reservas.
- Verificación de disponibilidad y ocupación de salas.

## Tecnologías utilizadas

- Python 3
- Programación orientada a estructuras de datos
- Manejo de listas y diccionarios
